# ⚡ VariantVault — Inventory Variant Manager

**Built for control, not chaos.**

VariantVault is a full-stack web app for managing product variants (sizes & stock) with a clean, structured workflow. It focuses on accuracy, simplicity, and real-time visibility of inventory.

---

## 💡 What it does

- Create products with multiple size variants  
- Track stock per variant  
- Prevent duplicate sizes  
- View total units and variant count  
- Search and manage products easily

## ⚙️ Features

- ➕ Add products with dynamic variant rows  
- 🔍 Search products instantly  
- 📊 Automatic variant + stock calculation  
- ❌ Duplicate size prevention  
- ✏️ Edit and update products  
- 🗑️ Delete with confirmation  
- ⚡ Clean, fast UI with server-side rendering  

---

## 🛠️ Tech Stack

- **Node.js + Express** — backend  
- **MySQL** — database  
- **EJS** — server-rendered views  
- **HTML / CSS / JS** — frontend

## 🚀 How to Run

```bash
git clone https://github.com/khanafnan110805/variantvault.git
cd variantvault
npm install
npm run dev
```

Then open:
http://localhost:3000
